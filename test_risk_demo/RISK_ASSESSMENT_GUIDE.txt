───────────────────────────────────────────────────────────────
RISK SCORING SYSTEM
───────────────────────────────────────────────────────────────

Points are awarded based on:

1. FILE EXTENSION:
   - High-risk (.exe, .dll, .bat, .sh, etc.) = +3 points
   - Medium-risk (.zip, .rar, .js, .sql, etc.) = +2 points
   - Normal (.txt, .pdf, .png, .csv, etc.) = +1 point

2. FILE SIZE:
   - Very large (>500 MB) = +2 points
   - Large (>100 MB) = +1 point
   - Normal = 0 points

3. RECENT MODIFICATION:
   - Modified within last 7 days = +1 point

4. SUSPICIOUS FILENAME:
   - Contains keywords (hack, crack, malware, exploit, etc.) = +2 points

FINAL RISK LEVEL:
   - Score ≥ 5 = HIGH RISK
   - Score ≥ 3 = MEDIUM RISK
   - Score < 3 = LOW RISK

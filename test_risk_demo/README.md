# Risk Assessment Test Files

This folder contains test files designed to trigger different risk levels:

## HIGH RISK FILES:
- suspicious_hack_tool.exe - Executable with suspicious name
- system_backdoor.dll - DLL file (executable type)
- malware_payload.bat - Batch script with suspicious name
- exploit_script.sh - Shell script with suspicious name

## MEDIUM RISK FILES:
- confidential_data.zip - Archive file
- database_backup.sql - SQL database file
- suspicious_script.js - JavaScript file
- large_archive.rar - Archive file

## LOW RISK FILES:
- meeting_notes.txt - Plain text document
- company_logo.png - Image file
- annual_report.pdf - PDF document
- employee_list.csv - CSV spreadsheet
